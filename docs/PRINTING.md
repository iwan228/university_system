# Печать: ведомости, протоколы и распоряжения

Этот документ описывает новую функцию печати (PDF) для модуля комиссий.

## Что добавлено
- Файл: `apps/commissions/printing.py` — сервис генерации PDF на основе `reportlab`.
  - `generate_commission_protocol_pdf(sheet, entries)` — протокол комиссии (таблица студентов + оценки).
  - `generate_commission_order_pdf(sheet, entries, order_text=None)` — распоряжение/приказ с текстом и списком студентов.
- Вьюхи: `commission_print_protocol` и `commission_print_order` в `apps/commissions/views.py`.
- URL'ы:
  - `/commissions/<sheet_id>/print/protocol/` — скачать протокол PDF
  - `/commissions/<sheet_id>/print/order/` — скачать распоряжение PDF (опционально с GET-параметром `?text=`)
- Добавлена зависимость `reportlab` в `requirements.txt`.

## Какие поля влияют на печатный документ (редактируемые поля)
- `CommissionSheet.subject` — название дисциплины (шапка документа).
- `CommissionSheet.date` — дата комиссии.
- `CommissionSheet.chairman` — председатель (показывается в шапке/нижнем колонтитуле).
- `CommissionSheet.member_1`, `member_2` — члены комиссии (в футере протокола).
- `CommissionEntry.grade` — оценка; отображается в таблице и в распоряжении.
- `CommissionEntry.notes` — примечания к записи; отображаются в таблице.
- `Student.full_name`, `Student.group`, `Student.student_id` — данные студента в таблице.

> Замечание: все перечисленные поля доступны для редактирования через существующие формы/вьюхи и моментально отразятся в печатных PDF.

## Примеры использования
- Скачать протокол (PDF):

```
GET /commissions/123/print/protocol/
```

- Скачать распоряжение с текстом:

```
GET /commissions/123/print/order/?text=Распоряжение%20о%20допуске
```

## Технические детали
- PDF генерируется на сервере библиотекой `reportlab` и отдается как `application/pdf`.
- Для больших ведомостей можно оптимизировать шрифты/разбиение по страницам; текущая реализация подходит для типичных размеров ведомостей.
- Если потребуется клиентская печать без диалога — это невозможно стандартными средствами браузера; используйте печать на стороне клиента (`window.print()`) или интеграцию с локальным браузерным агентом.

## Развертывание
1. Установите зависимость:

```bash
pip install -r requirements.txt
```

2. Перезапустите приложение (если в проде — процедуру деплоя).

## Тестирование
- Откройте страницу ведомости в интерфейсе, нажмите кнопку "Скачать Excel" или перейдите на URL `/commissions/<id>/print/protocol/` — вы получите PDF.
