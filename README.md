# Система учёта академических задолженностей

Веб-приложение для дирекции института (ИЭиТ) на базе Django. Позволяет импортировать данные о должниках из Excel-файлов, просматривать и фильтровать списки задолженностей, формировать ведомости комиссий и экспортировать результаты.

## Возможности

- **Импорт из Excel** — загрузка `.xls` / `.xlsx` файлов с данными о должниках (формат СДО/ведомостей)
- **Список должников** — таблица со всеми полями: институт, учебная сессия, ведомость, дисциплина, вид контроля, студент, статус, попытка, дата, оценка, курс, группа, форма обучения, специальность, преподаватель
- **Многоуровневые фильтры** — по ФИО, дисциплине, специальности, группе, курсу, институту, сессии, статусу, виду контроля
- **Экспорт в Excel** — выгрузка отфильтрованного списка в `.xlsx`
- **Ведомости комиссий** — создание, автозаполнение из должников, выставление оценок, экспорт в Excel
- **Панель администратора** — Django Admin для управления данными
- **Авторизация** — вход, регистрация (первый пользователь), контроль доступа

## Стек технологий

| Компонент | Технология |
|-----------|------------|
| Backend | Django 4.2 |
| База данных | SQLite3 |
| Импорт `.xls` | xlrd |
| Импорт/экспорт `.xlsx` | openpyxl |
| Фильтрация | django-filter |
| Формы | django-crispy-forms + crispy-bootstrap5 |
| Парсинг дат | python-dateutil |

## Быстрый старт

### 1. Клонирование

```bash
git clone https://github.com/<ваш-username>/university_system.git
cd university_system
```

### 2. Виртуальное окружение

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# Linux / macOS
source .venv/bin/activate
```

### 3. Установка зависимостей

```bash
pip install -r requirements.txt
```

### 4. Применение миграций

```bash
python manage.py migrate
```

### 5. Создание суперпользователя

```bash
python manage.py createsuperuser
```

### 6. (Опционально) Загрузка демо-данных

```bash
python manage.py seed_demo_data
```

### 7. Запуск сервера

```bash
python manage.py runserver
```

Откройте http://127.0.0.1:8000 в браузере.

## Импорт данных

1. Перейдите в **Импорт Excel** (боковое меню)
2. Загрузите файл `.xls` или `.xlsx` с ведомостью должников
3. Ожидаемый формат — стандартная выгрузка из СДО:

| Столбец | Поле |
|---------|------|
| A | № п/п |
| B | Институт |
| E | Учебная сессия |
| F | Ведомость |
| G | Дисциплина |
| I | Вид контроля |
| J | Студент (ФИО\|зачётка\|уровень) |
| K | Статус |
| L | Попытка |
| M | Дата попытки |
| N | Оценка |
| O | Курс |
| P | Группа |
| Q | Форма обучения |
| R | Специальность (код + название) |
| S | Преподаватель |

## Резервное копирование

```bash
# Создать резервную копию БД
python manage.py backup_db

# Восстановить из копии
python manage.py backup_db --restore backups/backup_20260301_120000.sqlite3
```
